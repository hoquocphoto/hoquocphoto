# Cosplay in character

This folder holds every photo in the **Cosplay in character** album (Portraits) on the website. What's here is what's on the site.

- **Add photos:** click **Add file → Upload files**, drag them in and click **Commit changes**. About two minutes later they're resized, renamed to the next number and live at the end of the album.
- **Remove a photo:** click it, open the **…** menu (top right), choose **Delete file** and click **Commit changes**. It leaves the website about two minutes later.
- **Captions** come from the file name of a new photo, e.g. `Kirribilli at dusk.jpg`. Camera names like `QUOC0127.JPG` get the album's usual caption.
- **Album cover:** start a new photo's name with `cover`, e.g. `cover - Milsons Point.jpg`.
