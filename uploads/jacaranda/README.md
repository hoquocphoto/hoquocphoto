# Jacaranda season

Photos you upload to this folder go into the **Jacaranda season** album (Portraits) on the website.

Click **Add file → Upload files**, drag your photos in and click **Commit changes**. About two minutes later they are resized, added to the end of the album and live on the site, and this folder is empty again.

- Name a photo after its place to caption it, e.g. `Kirribilli at dusk.jpg`. Camera names like `QUOC0127.JPG` get the album's usual caption.
- Start a name with `cover` (e.g. `cover - Milsons Point.jpg`) to make that photo the album cover.
